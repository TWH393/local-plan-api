模型 ID 留空可获取列表；选择 local-plan-default 跟随桥的默认模型。连接编辑框保存后，再保存管理员设置页面。

仅开放此应用的模型列表和聊天接口，管理页面不开放。停用后专用密钥立即失效。采样参数与输出 token 上限由上游控制。
